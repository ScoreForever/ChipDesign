# EDA results

This directory stores reviewable, lightweight evidence from ASIC synthesis,
place-and-route and post-layout simulation.  Each dated snapshot separates
formal course-level results from exploratory runs.

- [`2026-10-19`](2026-10-19/README.md): optimized `smaller_cpu` and `no_cpu`
  branches, plus the no-CPU die-size experiment.

Large implementation products and foundry/IP data are intentionally excluded
from Git.  Their sizes and SHA-256 values are recorded in each snapshot so the
server-side originals can be identified without redistributing PDK-derived
layout data.
