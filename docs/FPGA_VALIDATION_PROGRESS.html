04 / 当前问题

上板前仍需关闭的事项

按依赖顺序推进，而非同时堆叠新功能

问题 / 当前状态对 FPGA 验证的影响关闭条件
P0远程未见融合版综合结果当前 LUT / DSP / BRAM 和关键路径未知无法沿用 GAP 的 93.12% LUT 或 +1.841 ns WNS；需要确认融合阵列、量化 lane 和存储能否落入目标器件。当前提交的 synth / opt 资源、时序、完整 DRC 报告与 DCP；重新运行 BRAM 专项正反检查。
P0可复现 Vivado 工程待补齐历史脚本依赖外部 Lab6 引脚约束仓库配置 XDC 仅设置电压，不是完整引脚约束；clk_wiz_0 也需要明确 IP 生成配置。纳入板级引脚 / IOSTANDARD、Clocking Wizard 生成步骤、源清单和独立批处理入口。
P0布线后时序与 I/O 约束未验收远程未见当前版 place / route 报告综合网表估计不能覆盖实际互连、保持时间、JTAG 跨域和板级延迟。补齐约束与时钟关系，完成布局布线；提交 setup / hold、未约束路径和完整实现 DRC 审计。
P1JTAG / 装载 / 真实模型未上板闭环未找到实际板卡验收记录还不能证明真实时钟复位、debugger、SRAM 程序写入和结果读取可靠。bitstream 下载；LED / reset 检查；halt / resume、SRAM 读写；同一模型和向量在板上与 golden 比较。
P1DSP 流水线建议需重新审计历史版本保留 47 项性能建议若当前融合版关键路径涉及 DSP，可能需要寄存器改造；改造会影响阵列调度和延迟。先确认当前版路径，再决定是否加流水线；有 RTL 改动时重跑数值及逐周期对拍。
P2EDA 工具与检查覆盖边界Xcelium 可用；VCS / DC 暂不可用VCS 缺 libelf.so.1；DC 报 DCSH-1。Xcelium 不支持一项 deferred final 断言，默认 VCD 可见性有限。保持 Xcelium 可复现入口；需要 VCS / DC 时修复环境；专项补查该断言，调试波形启用 +access+r。

soc 上的 ASIC 技术库未指定，是映射综合的前置条件；它不替代 FPGA 目标器件与 Vivado 工程。当前没有可报告的 ASIC 面积、STA 或 FPGA 上板性能。
