# INT4 无 CPU NPU v2：算子扩展、真实模型、架构探索与 ASIC 实现

分支 `feature/int4-v2`，冻结标签 `int4-v2-freeze`。本文由 `docs/tools/int4_v2_report.py` 从
`docs/validation/int4_v2/` 下的结果文件生成；表中每个数字都能对应到其中一个 JSON 文件。
机器可读汇总：`docs/validation/int4_v2_summary.json`。

## 0. 结论

- **规格**：die 含 PAD 环 ≤ 1950 µm；两颗 RA1SHD_2048x32M8（各 8 KiB），模型与激活分开；4×8 INT4 阵列；50 MHz。
- **算子**：从 5 个扩到 7 个逻辑算子（Conv 含深度可分离与 1–7 矩形核、FC、MaxPool、AvgPool/GAP、Add、ReLU、Requant），
  每类融合都能单独开关；新增 u4 无符号激活张量。
- **模型**：7 个硬件友好模型在真实数据集上做 INT4 QAT，测试集精度全部来自与硬件逐位一致的整数推理（第 2 节），
  所有模型的若干测试帧都在 RTL 上开/关融合逐位核对。
- **芯片优化**：都以模型实测为依据（第 3、5、7 节）——单次舍入 Requant、u4 激活、紧凑参数、共享建立乘法器、
  向量化 element 引擎、行填充、单行深度可分离权重、双 Requant lane、原地 Add、JTAG 突发。
- **端到端**：每次推理的时间由 JTAG 传输主导；突发协议把线上时间和主机 RPC 次数都大幅降低（第 4 节）。
- **布局与签核**：SRAM 的 109 个信号引脚都在宏底边；新增让引脚朝向逻辑区的朝向和布局，并作为物理检查项。
  选定 `west_stack_r90`、利用率 70%：die 1860 µm（上限 1950），Calibre DRC/LVS、PrimeTime、Formality 和 Xcelium SDF 门级仿真全过（第 6 节）。
- **FPGA**：本轮不上板、不跑 Vivado；按上一版上板经验留出余量（第 5 节）。

## 1. 相对 ABI 3（INT4 v1）的改动

| 类别 | 改动 | 依据 |
|---|---|---|
| 算子 | 深度可分离卷积（复用阵列，权重装载时展开成块对角） | 8 KiB 模型 SRAM 下，DS 结构是参数最省的卷积 |
| 算子 | 1–7 的矩形核，1D 卷积原生运行 | HAR/ECG 1D 模型；KWS 7×3 前端 |
| 算子 | 独立 Max/Avg 池化任意窗口/步长；GAP；融合 1×2 池化 | ECG 1D 池化（v1 直接拒绝）；GAP 头 |
| 算子 | 残差 Add（两路 8-bit 整数权重），可原地写回任一操作数 | 残差块；原地可少占一个张量 |
| 融合 | 融合开关按种类或按头算子设置，单节点可关闭；池化/Add 后可融合 Requant/ReLU | 融合消融（第 3.5 节） |
| 数值 | Requant 单次舍入（v1 舍入两次） | 第一层约 8% 输出与实数结果差 1，QAT 无法对齐 |
| 数值 | u4 无符号激活（ReLU 后 0..15） | ReLU 后有符号 INT4 只剩 3 位；QAT 对比各模型 +1–2.5 个百分点 |
| 数值 | 参数一字一通道：18-bit bias + Q8 乘数 + 6-bit 移位 | Q8 与 Q15 全测试集精度相同；参数 SRAM 减半 |
| 吞吐 | 向量化 element 引擎：一次读 8 个 nibble 更新全部通道 | Add/GAP 占 10–34% 周期 |
| 吞吐 | 单通道窄核（kw≤4）行填充：每个 K 组一次连续读 | KWS 7×3 前端 67% 周期在等激活 |
| 吞吐 | 双 Requant lane，相邻两个 nibble 合并一次写回 | 等结果槽占 KWS 周期 24% |
| 容量 | 深度可分离权重每个 tap 只存一行（v2 首版存两份） | GTSRB 模型 8228 → 7688 B |
| 主机 | JTAG 突发写/读 IR（每字一次 32-bit 扫描），主机批量 RPC | 实板每次 RPC 4 ms，逐字协议每字 ≥3 次 RPC |
| 面积 | ~20 个建立阶段乘法器改为共享一个；写回地址增量计算；保留字取指时检查 | Genus 寄存器级面积分解 |
| 布局 | SRAM 可分别设置朝向；`west_stack_r90`、`south_row_mx`；引脚朝向物理检查 | 宏引脚全在底边，v1 摆法两颗宏都背对逻辑 |

ABI 号 0x00040000；描述符格式、参数字和 trace 版本见 `docs/CPU_LESS_CONTROL.md` 与第 8 节。

## 7. 架构探索：采纳与否决

每一项都先在模型上测量，再做取舍；“依据”列是做决定时的数据。

| 选项 | 结论 | 依据 |
|---|---|---|
| Requant 单次舍入 | **采纳** | 两次舍入使第一层 ~8% 输出偏一档，QAT 伪量化与整数推理差 >10 个百分点；改后第一层只差 0.24% |
| u4 无符号激活 | **采纳** | QAT 伪量化：MNIST 95.2→96.6、Fashion 85.0→86.8、ECG 验证 96.4→96.9；MAC 位宽 5×4，10-bit 局部和与 18-bit psum 不变 |
| 参数 8 B → 4 B（Q8 乘数、18-bit bias） | **采纳** | HAR 92.84→92.74、GTSRB 80.54→80.59（全测试集）；最大 |bias| 318；参数区减半、缓存每 lane 48→26 bit |
| 共享建立乘法器 + 增量地址 + 取指检查 | **采纳** | 标准单元 1.199 → 1.047 mm²（−12.7%），每个描述符/tile 约多 10 拍 |
| 向量化 element 引擎 | **采纳** | ECG −30%、KWS-L −19%、MNIST-L −19% 周期 |
| 窄核行填充、RGB 补到 4 通道 | **采纳** | KWS/GTSRB 第一层分别有 67% / 60% 周期在等激活；补通道结果逐位相同 |
| 深度可分离权重每 tap 一行 | **采纳** | GTSRB-L 8228 → 7688 B，否则 4×8 构建放不下 |
| 双 Requant lane | **采纳** | 等结果槽占 KWS-L 24%；冻结版累计 −19% 到 −43% 周期 |
| 原地 Add | **采纳** | Fashion 残差块在 14×14×24 处否则需同时存活 3 个张量 |
| SRAM 旋转 R90、引脚朝东（`west_stack_r90`） | **采纳** | 同为 u70 时 die 1920 → 1860 µm；引脚背对逻辑的 `west_stack` 只能靠更大 die 绕线（第 6 节） |
| Innovus hold 目标 0.02 → 0.15 ns | **采纳** | PrimeTime 在 SPEF 上读出的 hold 比 Innovus 差约 0.1 ns（复位同步器 −0.083 ns）；提高目标后 PT hold +0.042 ns，setup 仍 +0.709 ns |
| JTAG 突发 IR | **采纳** | 实板每次 RPC 4.0 ms；逐字协议每个字 ≥3 次 RPC（第 4 节） |
| TILE 16 → 8（psum 减半） | 保留为编译选项，默认 16 | −0.06 mm²，周期几何平均 +4.1%（KWS-M +15.5%）；两颗 SRAM 的 die 不受面积限制 |
| 第三颗 SRAM（模型 16 KiB） | **否决** | 只有 8 KiB 宏可用（其余为 128/256 KiB）；u70 下标准单元须 ≤~1.0 mm² 才能放进 1950 µm，余量 <5 µm；所有模型已 >90% |
| 模型与激活共用一颗 SRAM | **否决** | 7 个模型中多数“模型字节 + 激活峰值”超过 8 KiB（第 2 节） |
| 硬件全局关融合寄存器 | **否决** | 融合改变描述符个数和张量分配，硬件无法事后拆开；由编译器按种类开关 |
| 每个算子单独 `ifdef` 裁剪 | 暂不需要 | 关掉 trace 后 FPGA 估算已有 ~26% LUT 余量 |
| 深度可分离专用数据通路 | 未做 | 广播阵列上 DW 每拍只用 4/32 个 MAC；需要新的逐列激活通路，面积代价大，留作后续 |

## 8. 验证

- **程序回归**（Icarus，`run_program_regression.py`）：32 个 fixture × 融合/不融合 × 4×8 / 4×4 / 4×8 JTAG，
  共 130 项，逐条核对每个张量写回事件；另有 16 个非法描述符（含 7 个 ABI 4 字段）和生命周期/中止/超时检查、
  20000 个 Requant 向量（独立的有理数模型）、INT4/u4 MAC 穷举、存储与背压单元测试。行为 SRAM、
  `CHIPDESIGN_FPGA_MEM` 配置和 TILE=8 构建分别全过。
- **模型级**：每个模型若干测试帧在 RTL 上开/关融合逐位一致（`software/zoo/rtl_check.py`）；
  `npu_fastref`（全测试集评分）与纯 Python `reference()` 在抽样帧上逐位一致。
- **端到端**：物理 JTAG 管脚 + 1 MHz TCK，突发与逐字两种协议都跑完整主机流程。
- **ASIC**：Genus 综合（限定范围的 mailbox CDC 约束与审计）、Innovus 全芯片 PnR（9 项物理检查 + CDC + SRAM 引脚朝向）、
  独立签核和 Xcelium SDF 门级仿真（结果见第 6 节）。门级测试走突发 IR，覆盖融合 Conv/Pool、DW、原地 Add、AvgPool、
  通用 MaxPool 和 u4 张量。
- **FPGA**：未上板、未运行 Vivado；`nocpu_board_suite.py` 与证据检查已覆盖 ABI 4 的 fixture，单元测试通过。

## 9. 不覆盖的范围与风险

- 只有 TT 1.8 V 25 °C 单角；无多角 STA、IR/EM、密封环与芯片级 ESD 评审；功耗为无激励估算。
- Innovus 与 PrimeTime 的 hold 结果相差约 0.1 ns；选定版图靠提高 Innovus hold 目标收敛，PT hold 余量只有 +0.042 ns，多角下需复查。
- SRAM 接口时序只由 Innovus 检查（PrimeTime 中宏为黑盒）。
- FPGA 余量来自 yosys 估算（与 Vivado 在上一版相差 2%），不是 Vivado 实现结果，也没有上板。
- 主机 RPC 时间用上一版实板的中位数外推；突发协议在真实 FT232H/OpenOCD 上的批量开销未实测。
- ECG 采用常见的病人内划分（同一病人的心拍可同时出现在训练和测试集），比病人间划分容易；balanced 精度另列。
- GTSRB 训练集用的是 HF 镜像的 26,640 张子集；测试集是官方 12,630 张。
- KWS 的 “unknown/silence” 两类按标准做法构造（未知词抽样到与关键词相当，静音来自背景噪声片段）。
- DW 阵列利用率低（4/32）是结构性限制；更大的模型受 8 KiB 模型 SRAM 约束。
