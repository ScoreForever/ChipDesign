# no_cpu 本轮现场操作确认

本文件记录当前对话的 no_cpu / ABI 2.1 操作，不引用 INT4 的现场结果。

- 首个监测窗口过期后用户才同时回复旧按键确认及“现在可以，等待新窗口”；旧窗口仍记未覆盖，没有追认。
- 用户随后确认在重开窗口中按 RST/S6，日志显示发生在任务间；又一次确认按键同样未取得 busy 前采样。全局复位清零及新推理单独验证通过。
- 最后一次用户在新监测窗口确认“已按 RST/S6 并松开”，对应 `physical_button/report.json` 的 last_valid_status=3、TAP 中断和全局清零。这是功能采样证据，没有模拟边沿时刻证据。
- 用户确认“已全部断电，灯已熄灭”；主机记录两组相关 USB 设备消失，再等待 10 秒才提示接回。
- 用户确认“已重新接电并连接 USB”；此后重新下载同一 no_cpu 50MHz 镜像，完成全局初始状态、FC 输出及内部数字 trace 验证。

按住时长与灯灭依赖用户现场执行；没有示波器/逻辑分析仪或电源轨测量。软件观测时间见各原始 JSON/RPC 日志，不等同于物理复位边沿时间。
